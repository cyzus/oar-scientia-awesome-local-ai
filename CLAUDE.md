# Awesome Local AI — AI Agent Guide

## Purpose
Curated list of local-first, self-hosted AI tools and frameworks.
Follows the "awesome list" format (https://github.com/sindresorhus/awesome).
Positions LunoLabs as a thought leader in the local AI space.

## Structure
Single-file awesome list in README.md with sections:
- Inference Engines, Models, RAG, Agents, MCP, Vector DBs
- UI, Voice, Image, Hardware, Deployment, Privacy

## Conventions
- All entries must be self-hostable or locally runnable
- Table format: Tool | Description | (optional: Language/Price)
- Link to official GitHub repo or website
- Keep entries sorted alphabetically within sections
- No proprietary cloud-only tools
- Verify tools are actively maintained (last commit < 12 months)
- Use consistent formatting across all sections
