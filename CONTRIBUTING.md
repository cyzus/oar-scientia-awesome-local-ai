# Contributing to Awesome Local AI

Thanks for contributing! Here's how:

## Adding a Tool

1. Fork this repo
2. Add your entry to the appropriate section in README.md
3. Use the table format: `| [Tool](link) | Brief description |`
4. Keep entries alphabetically sorted within their section
5. Open a PR with a brief explanation of why the tool fits

## Rules

- **Must be local-first or self-hostable** — no cloud-only services
- **Must be actively maintained** — last commit within 12 months
- **Must have a working link** — to official repo or website
- **One tool per PR** makes review easier
- **Brief descriptions** — one line, factual, no marketing language

## Removing a Tool

If a tool is no longer maintained or relevant, open an issue explaining why.
